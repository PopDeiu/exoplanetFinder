1. PREZENTARE GENERALĂ

1.1 Despre Proiect

ExoplanetFinder este o aplicație web interactivă construită cu Streamlit, concepută pentru explorarea și analiza datelor din misiunile spațiale TESS și Kepler. Aplicația oferă un interfață user-friendly pentru:

  • Căutarea și analiza stelelor după identificatori (TIC, TOI, KIC)
  • Explorarea sistemelor cunoscute cu candidați și planete confirmate
  • Analiza și identificarea semnalelor false pozitive
  • Descoperirea țintelor potențial netestare
  • Ajustarea parametrilor de analiză în timp real

1.2 Obiectivele Aplicației

  • Furnizare de acces ușor la datele publice din TESS și Kepler
  • Crearea unei platforme interactivă pentru analiza curbelor de lumină
  • Facilitarea procesului de descoperire de potențiale exoplanete
  • Generarea rapoartelor în format PDF pentru rezultatele analizei
  • Oferirea unei interfețe configurabile pentru parametrii analizei

1.3 Público-țintă

  • Pasionații de astronomie
  • Cercetători care lucrează cu datele TESS/Kepler
  • Studenți și doritori de aprofundare în analiza datelor spațiale
  • Oricine dorește să exploreze datele exoplanetelor

3.2 Rolul Fiecărui Fișier Cheie

exo_app.py - Pagina Principală

Fișierul de intrare al aplicației. Inițializează:

  • Configurarea paginii Streamlit (layout, title)
  • Stilurile și temele UI (fundal cosmic)
  • Session state pentru gestionarea datelor în sesiune
  • Încărcarea setărilor persistente din fișier
  • Interfața pagini principale cu navigare către alte pagini

requirements.txt

Listează toate bibliotecile Python necesare. Se instalează cu:

pip install -r requirements.txt

pages/ - Paginile Aplicației

Streamlit detectează automat fișierele named cu prefixul numeric din folderul pages/ și le afișează în sidebar ca pagini navigabile. Fiecare pagină are o responsabilitate specifică.

4. COMPONENTE PRINCIPALE

4.1 ui_styles.py - Stilizare și Teme

Module responsabil pentru styling-ul UI al aplicației:

  • set_galaxy_background() - Aplică fundal cu gradient cosmic
  • set_sidebar_style() - Stilizează sidebar-ul
  • apply_pro_plotting_style() - Configurează tema Dark Mode pentru Matplotlib
Gradienți disponibili: default, nebula, void, cosmic, stellar

4.2 settings_manager.py - Gestionare Setări

Gestionează salvarea și încărcarea setărilor persistente ale aplicației:

  • load_settings() - Încarcă setări din fișierul JSON
  • save_settings() - Salvează setări în fișierul JSON
  • get_setting() - Obține o anumită setare
  • update_setting() - Actualizează o setare

Setări Persistente Disponibile

Setare Tip Valoare Default Descriere
bin_size int 10 Dimensiunea binning pentru agregare date
sigma_val float 5.0 Prag sigma pentru outliers
period_range list[float] [1.0, 30.0] Interval perioade de căutare (zile)
selected_missions list[str] ["TESS", "Kepler", "K2"] Misiuni selectate pentru căutare
selected_authors list[str] ["SPOC", "Kepler"] Sursele de date preferate

4.3 data_fetchers.py - Preluare Date

Gestionează interogările la baze de date astronomice externe:

  • get_toi_catalog() - Descarcă catalogul TESS Objects of Interest (TOI)
  • search_toi_catalog() - Filtrează catalogul TOI cu criterii
  • fetch_star_data() - Preia date despre o stea
  • get_star_parameters() - Obține parametri stelari specifici
  • fetch_catalog_targets() - Descarcă ținte din cataloage
  • fetch_untested_targets() - Identifică ținte potențial netestare
Funcțiile au cache de 24 ore (TOI) și 7 zile (date stele) pentru performanță optimă.

4.4 analysis_engine.py - Motor de Analiză

Conține logica principală pentru procesarea și analiza curbelor de lumină:

  • process_selected_data() - Procesează datele selectate
  • generate_pdf_report() - Generează raport PDF cu rezultate
  • Utilizează Box Least Squares (BLS) pentru identificare perioade
  • Efectuează normalizare și filtrare date

5.6 6_Star_explorer.py - Explorator Avansat

Funcționalitate principale:

7. GHID DE DEPLOYMENT

7.1 Deployment cu Docker Compose

Aceasta este modalitatea recomandată pentru deployment în producție.

Cerințe Preliminare

  • Docker Desktop (Windows/Mac) sau Docker Engine (Linux)
  • Docker Compose (integrat în Docker Desktop 1.27+)

Pași de Deployment

1. Verificare Instalare Docker
docker --version docker compose version
2. Build și Pornire Container
cd c:\Exoplanete\exoplanetFinder docker compose up --build
Notă: Pe unele versiuni mai vechi de Docker, comenzile ar putea fi:
docker-compose up --build
3. Acces la Aplicație

Odată cu build-ul completat, aplicația va fi disponibilă la:

http://localhost:8501
4. Oprire Container
docker compose down

7.2 Configurare Docker Compose

Fișierul docker-compose.yml conține:

  • version: '3.8' - Versiunea Docker Compose API
  • services.app: Serviciul principal al aplicației
  • image: exoplanetfinder:latest - Imaginea Docker
  • build: . - Build dintr-un Dockerfile în directorul curent
  • restart: unless-stopped - Restart automat dacă cade
  • ports: "8501:8501" - Port mapping (host:container)
  • environment: Variabile de mediu pentru Streamlit

7.3 Configurare Dockerfile

Dockerfile definește pas cu pas cum se construiește imaginea containerului:

FROM python:3.9-slim WORKDIR /app COPY requirements.txt . RUN pip install --no-cache-dir -r requirements.txt COPY . . EXPOSE 8501 CMD ["streamlit", "run", "exo_app.py", "--server.port=8501", "--server.address=0.0.0.0"]

7.4 Parametrii Streamlit Server

Parametru Valoare Descriere
STREAMLIT_SERVER_HEADLESS true Mod fără interfață grafică (container)
STREAMLIT_SERVER_ENABLE_CORS false Dezactiva CORS (securitate)
STREAMLIT_SERVER_ENABLE_XSRF_PROTECTION false Dezactiva XSRF (pentru producție, revizui)
STREAMLIT_SERVER_ADDRESS 0.0.0.0 Bindez la toți interfețele de rețea
--server.port 8501 Portul pe care rulează Streamlit
⚠️ Notă de Securitate: Pentru producție, revizuiți setările CORS și XSRF. Dezactivarea lor este acceptabilă pentru development, dar trebuie re-evaluată pentru mediile publice.

8. PROCESUL DE CONFIGURARE

8.1 Setări Persistente

Setările aplicației sunt salvate în fișierul settings.json în directorul root al proiectului.

Structura settings.json

{ "bin_size": 10, "sigma_val": 5.0, "period_range": [1.0, 30.0], "selected_missions": ["TESS", "Kepler", "K2"], "selected_authors": ["SPOC", "Kepler"] }

8.2 Session State

Streamlit utilizează session state pentru a gestiona datele în cadrul unui sesiune:

  • search_result - Rezultatele căutării unei stele
  • explore_planets_results - Datele din pagina de explorare planete
  • explore_fps_results - Datele din pagina false positive
  • untested_results - Țintele netestare identificate

8.3 Cache-ul Aplicației

Pentru performanță optimă, aplicația utilizează cache pentru datele descărcate:

  • TOI Catalog: Cache 24 ore
  • Date Stele: Cache 7 zile
  • Curve de Lumină: Descărcate din Lightkurve/MAST
Cache-ul este gestionat automat de Streamlit cu decoratorul @st.cache_data(ttl="1d")

8.4 Personalizare Teme

Aplicația suportă multiple teme de fundal cosmic:

  • default - Gradient albastru-violet standard
  • nebula - Culori de nebuloasă purpurie
  • void - Void cosmic radiant
  • cosmic - Gradient cosmic abstract
  • stellar - Gradient conic (stellar)

8.5 Variabile de Mediu

Seturi importante de variabile de mediu (dacă sunt necesare în viitor):

  • STREAMLIT_SERVER_ADDRESS - Adresa server (default: localhost)
  • STREAMLIT_SERVER_PORT - Port server (default: 8501)
  • PYTHONUNBUFFERED - Output fără buffer (util în logs)

9. ARHITECTURA APLICAȚIEI

9.1 Fluxul de Date

Aplicația urmează o arhitectură standard web:

[Utilizator] ↓ [Browser - Interfață Streamlit] ↓ [Backend Python - Logic & Processing] ↓ [Baze de Date Externe - MAST, ExoFOP, TOI] ↓ [Vizualizare Rezultate - Matplotlib, Plotly] ├→ [Grafice Interactive] ├→ [Tabele Date] └→ [Rapoarte PDF (ReportLab)]

9.2 Componentele Functionali

Frontend Layer

  • Streamlit UI components (buttons, sliders, text input)
  • Plotly interactive charts
  • Custom CSS styling (galaxy background)

Business Logic Layer

  • Data fetching și preprocessing
  • Analysis engine (BLS algorithm)
  • Settings management
  • PDF report generation

Data Layer

  • External API calls (Astroquery)
  • Local cache (Streamlit @cache_data)
  • Settings persistence (JSON file)

9.3 Fluxul Unei Sesiuni Tipice

  1. Utilizatorul deschide aplicația în browser
  2. exo_app.py inițializează session state și setări
  3. Utilizatorul selectează o pagină din sidebar
  4. Pagina respectivă se execută și afișează formularul/interfața
  5. Utilizatorul introduce input (nume stea, criterii filtrare)
  6. Aplicația apelează data_fetchers.py pentru preluare date
  7. Datele sunt procesate cu analysis_engine.py
  8. Rezultatele sunt vizualizate cu Matplotlib/Plotly
  9. Utilizatorul poate genera raport PDF
  10. Setări modificate sunt salvate în settings.json
